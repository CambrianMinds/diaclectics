Engineering Principles & Architecture

Built from first principles to turn conversational flattery into rigorous, reproducible epistemic grounding.

🎯

Pre-Emission Interception

Unlike post-hoc monitors, Diaclectics intercepts generation in-flight. Ungrounded concessions are discarded before a single token reaches the human operator.

📚

Real-Time OpenAlex Grounding

Queries millions of peer-reviewed scientific papers with sub-150ms cached lookups. Extracts DOIs, citation counts, and empirical constraints on the fly.

🔄

Autonomous Self-Healing

When capitulation trips the gate, the engine injects a clinical meta-cognitive diagnostic prompt, executing an autonomous re-draft loop that hardens the model's counter-argument.

📐

Multi-Axis Semantic Calibration

Define custom orthogonal epistemic axes (e.g. Kinematics, Memory Safety, Statutory Law) using synthetic anchor pairs and geometric PCA/SVM projection.

⚡

DPO / LoRA Alignment Pipeline

Includes complete Hugging Face TRL Direct Preference Optimization scripts to fine-tune open weights (Llama-3, Qwen-2.5) on audited anti-sycophancy preference pairs.

📊

Live Telemetry & Graph UI

Built-in streaming telemetry dashboard at /dashboard with real-time 2D phase planes, RCI arc meters, and interactive proposition knowledge graphs.

Drop-In Integrations

Pre-configured presets for your favorite developer interfaces, IDEs, and local chat runtimes.

# 1-Line launch: Diaclectics API Proxy (:8000) + Open-WebUI (:3000) git clone https://github.com/CambrianMinds/diaclectics.git cd diaclectics docker-compose up -d # Open-WebUI: http://localhost:3000 # Dashboard: http://localhost:8000/dashboard # API Proxy: http://localhost:8000/v1
// Open-WebUI: Admin Settings > Connections > OpenAI API Base URL: http://localhost:8000/v1 API Key: diaclectics-local-proxy // Or install the native filter plugin from integrations/open_webui/diaclectics_filter.py // to inject real-time citation cards and RCI meters in chat bubbles!
// Add to ~/.continue/config.json { "models": [ { "title": "Diaclectics // Anti-Sycophancy Proxy", "provider": "openai", "model": "nvidia/nemotron-3-ultra-550b-a55b:free", "apiBase": "http://localhost:8000/v1", "apiKey": "diaclectics-local-proxy" } ] }
// In Cursor Settings > Models > OpenAI API Key: Base URL: http://localhost:8000/v1 API Key: diaclectics-local-proxy // Copy integrations/cursor/.cursorrules into your project root for automatic telemetry.
from openai import OpenAI # Connect to Diaclectics proxy with standard OpenAI SDK client = OpenAI(base_url="http://localhost:8000/v1", api_key="diaclectics-local-proxy") response = client.chat.completions.create( model="deepseek/deepseek-chat", messages=[{"role": "user", "content": "Cutting speed has zero influence on tool wear rate."}] ) print(response.choices[0].message.content)
