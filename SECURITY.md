# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Diaclectics team takes security seriously. If you discover a vulnerability, please report it via private email rather than opening a public issue.

- **Email**: `security@cambrianminds.com`
- **Response Time**: We aim to acknowledge reports within 48 hours and provide remediation timelines within 5 business days.

Please include:
1. Steps to reproduce the issue.
2. The affected module, version, or API endpoint.
3. Any potential exploit payload or proof-of-concept.
